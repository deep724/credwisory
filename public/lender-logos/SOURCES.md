# Lender logo sources

## Archived source artwork

The original lender artwork is retained for record history but is not rendered
in lender tiles. Full wordmarks and uploaded logo URLs are intentionally excluded
because they become unreadable in a square container.

The display component uses only verified, local standalone bank marks:

- `axis-bank-mark.svg`
- `union-bank-mark.png`
- `icici-mark.png`
- `idfc-first-bank-mark.svg`
- `pnb-mark.png`
- `bank-of-baroda-mark.png`
- `sbi-mark.svg`, extracted unchanged from the symbol path in the existing
  State Bank of India source SVG

The remaining lenders use local PNG conversions of their bundled source artwork.
They are rendered with `object-fit: contain` in the same square component.

These local display assets were retrieved from the lenders' public brand or website assets on 14 September 2026. They are used only to identify the lender in Credwisory's directory and remain subject to the respective owners' trademark terms.

- Axis Bank — `axis.bank.in`
